## Inspiration

[AltTab](https://github.com/lwouis/alt-tab-macos), by lwouis and its contributors,
inspired the individual-window switcher, thumbnail grid, and recency ordering.
AltTab is a separate project distributed under GPL-3.0. ScreenTap is not an
official AltTab release or endorsed by that project.

During this development session, cloning the upstream repository failed because
of network restrictions. ScreenTap's source was written separately using macOS
SDKs; upstream implementation files, icons, and other bundled assets were not
copied. Public project descriptions and memory-related issue discussions were
consulted. See docs/architecture.md for the research scope.

Any future incorporation of upstream GPL-covered code must preserve the relevant
copyright and license notices and comply with the GPL. This MIT notice does not
relicense code owned by AltTab or other third parties.

## Dependencies and product images

ScreenTap has no third-party runtime packages. It uses Apple system frameworks.
Apple, macOS and other third-party application names belong to their respective
owners. Marketing images are rendered with ScreenTap's production grid renderer
using original, synthetic demo-window content; they contain no private user data.
